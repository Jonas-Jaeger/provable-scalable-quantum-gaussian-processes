Quantum Gaussian Process Bayesian Optimization for synthetic 2D example and quantum sensing (QS) application.

Synthetic example:
- Data in data_BO_2D
- Data generation via BO_TNs.ipynb
- Run BO via BO_multi_dim_idx_mode.ipynb
- Plot BO results via BO_multi_dim_idx_mode_plotting.ipynb

Quantum sensing application:
- Data in data_BO_QS
- Data generation via BO_QS_TNs.ipynb
- Run BO via BO_grad_simplified.ipynb
- Plot BO results via BO_grad_plotting_new.ipynb
